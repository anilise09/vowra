## Generation prompt pattern

Built-in image generation, `photorealistic-natural`: a completely fictional, clearly adult person in a natural public setting; realistic candid smartphone portrait; authentic texture; fully clothed; crop-safe vertical framing; no other people, text, logo, watermark, UI, sexualized pose, minor, celebrity resemblance, or excessive retouching.
